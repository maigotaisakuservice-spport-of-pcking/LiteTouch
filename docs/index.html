エンタープライズ基準の4つのコアモジュール

用途に合わせて単体モジュールまたは全部入り（all.js）を柔軟に選択できます。

🧭

1. ガイド ＆ ツアーモジュール

新機能案内やオンボーディングツアーをターゲット要素の横にポップアップ表示。全画面暗転オーバーレイや「次へ/戻る」進捗ナビゲーションに対応。

⚡

2. EFO 入力リアルタイム指導

離脱の原因となるフォーム入力エラー（(株)などの略称、未入力、メアド形式）を `blur` 時にリアルタイム検知して指導。CVR低下を防ぎます。

💡

3. クイックメニューポータル

画面右下に固定ヘルプアイコンを常駐。1タップでFAQや各種手続き導線リンクをまとめたダイアログが展開し、ユーザーの迷いを解消します。

🤖

4. AutoFlow (フォーム自動操作)

デモや定型操作を完全自動化。React/VueのVirtual DOM Stateに直接連動する Native Value Setter バイパス処理で確実に値をセット・クリックします。
